# KruSine Smart Games

เว็บไซต์สื่อการเรียนรู้ภาษาไทย อ้างอิงโครงหน้าสาธารณะของ ar.krucom.net

## ใช้งานในเครื่อง

ติดตั้ง dependencies ตาม pnpm-lock.yaml แล้วใช้ `pnpm dev` สำหรับพัฒนา และ `pnpm build` สำหรับสร้างไฟล์เผยแพร่
ฐานข้อมูลใช้ D1 binding `DB` และ migration ใน `drizzle/` ผ่าน Sites hosting
การเข้าสู่ระบบจริงใช้ Sign in with ChatGPT ของ Sites

## ที่สร้างแล้ว

- หน้าแค็ตตาล็อก ค้นหาและกรอง เกมต้นฉบับ 6 ชุด
- เล่นแบบแตะจอ ฟังเสียง และตรวจจับนิ้วค้างบนตัวเลือกผ่านกล้อง
- แบบทดสอบก่อนเรียน เนื้อหาทบทวน และแบบทดสอบหลังเรียน (เปรียบเทียบภายในรอบ ไม่เก็บประวัติบทเรียน)
- สร้าง แก้ไข บันทึกและแบ่งปันชุดคำถาม พร้อมนำเข้า/ส่งออก Excel และรูปผ่าน HTTPS URL
- คะแนนส่วนตัวและอันดับแบบสมัครใจ คะแนนชุดที่แก้เองไม่รวมอันดับมาตรฐาน
- ห้องแข่งหลายอุปกรณ์ รหัส 6 ตัว ครูควบคุมเฉลย และอันดับจริง สูงสุด 100 คนตามข้อจำกัดระบบ (ยังไม่ได้ทดสอบโหลด 100 คน)
- โปรไฟล์ ชุดของฉัน ข้อความติดต่อที่เก็บในฐานข้อมูล และ QR แชร์ลิงก์
- หน้าแพ็กเกจ วิธีใช้ ความเป็นส่วนตัวและเงื่อนไข

## ยังไม่พร้อมเปิดบริการเต็มรูปแบบ

- ยังไม่มีการเชื่อมผู้ให้บริการชำระเงินหรือเปิดสิทธิ์ GO/PRO อัตโนมัติ ราคาเป็นตัวอย่างและไม่มีการเก็บเงินจริง
- บัญชีอีเมล/รหัสผ่านแบบต้นแบบไม่ได้สร้าง ใช้ระบบบัญชี Sites แทน
- ไม่ได้คัดลอกคลังเกมของต้นแบบ และยังไม่มีเกมทุกกลไก เช่น ตกปลา เขาวงกต ติดตามร่างกาย หรือปาก
- หน้าภายในบัญชีต้นแบบบางส่วนยังไม่ได้รับอนุญาตให้ตรวจ จึงยังเทียบความครบถ้วนไม่ได้
- ไม่มีหน้าแอดมินจัดการข้อความติดต่อหรือการสมัครสมาชิก
- รูปภาพรองรับ URL ยังไม่ใช่ระบบอัปโหลดไฟล์ภาพ
- เว็บไซต์เดิมเป็นส่วนตัว นักเรียนต้องได้รับสิทธิ์เข้าถึงก่อนใช้ลิงก์หรือห้องแข่ง

## ผลตรวจ

TypeScript และ production build ผ่าน
ทดสอบ HTTP กับฐานข้อมูล D1 ในเครื่อง: แยกสิทธิ์ชุดส่วนตัว ปฏิเสธการแก้ไขของบัญชีอื่น บันทึกโปรไฟล์ คำนวณคะแนนฝั่งเซิร์ฟเวอร์ ป้องกันส่งคะแนนซ้ำ สิทธิ์ครูควบคุมห้อง ซ่อนเฉลย รับหนึ่งคำตอบต่อผู้เล่นและข้อ สรุปคะแนน และ 7 หน้าหลักผ่าน
ยังไม่ได้ทดสอบการอนุญาตกล้องจริง เสียงจริง หรือภาพหน้าจอเบราว์เซอร์

## สถานะส่งมอบ

แพ็กเกจ build อยู่ที่ `work/krusine-smart-games-package.tar.gz` พร้อม hosting manifest และ migrations
การอัปเดตออนไลน์ถูกบล็อก: Sites get_site ตอบ Sites project not found สำหรับ project_id ใน `.openai/hosting.json` วันที่ 9 กันยายน 2026 ต้องคืนการเข้าถึงโปรเจกต์เดิมก่อน push / save / deploy ห้ามสร้างโปรเจกต์ซ้ำหรือเปลี่ยน id โดยเดา

## หลังบ้านจัดการเกม

เปิด `/admin` แล้วเข้าสู่ระบบบัญชีเจ้าของเกม เพิ่มเกมใหม่หรือเริ่มจากแม่แบบ แก้ไขชื่อ วิชา ระดับชั้น รายละเอียดและคำถาม บันทึกเป็นฉบับร่างหรือเปิดแสดงบนหน้าแรก/คลังบทเรียน ทำสำเนา ย้ายถังพัก และกู้คืนได้ การกู้คืนและทำสำเนาจะเป็นฉบับร่างเสมอ สิทธิ์จัดการจำกัดเฉพาะเกมของบัญชีนั้น ไม่ใช่สิทธิ์ผู้ดูแลข้อมูลทุกบัญชี

ต้องใช้ migration `0002_sad_mathemanic.sql` เพื่อเพิ่มรายละเอียดและระดับชั้น ทดสอบฐานข้อมูลในเครื่องผ่านทั้งการสร้าง แก้ไข การแสดงผลตามสถานะ ทำสำเนา ถังพัก กู้คืน การปฏิเสธบัญชีอื่นและคำขอข้ามเว็บไซต์
